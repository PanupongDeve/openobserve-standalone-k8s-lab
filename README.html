Enterprise Observability Lab Environment

OpenObserve Standalone on Kubernetes

ระบบ Observability รวมศูนย์สำหรับเก็บ Metrics และ Container Logs แบบครบวงจรบน Kubernetes ใช้ kube-prometheus-stack (Agent Mode) ยิง Remote Write ตรงเข้า OpenObserve พร้อม OpenTelemetry Collector DaemonSet อ่านล็อกระดับ Pod อัตโนมัติ จัดเก็บถาวรด้วยไฟล์ Parquet บน MinIO S3 พร้อมนโยบาย Data Retention และชุดทดสอบความทนทาน (Resilience Verification)

Visual Architecture & Data Pipelines

โครงสร้างการทำงานและเส้นทางข้อมูล

METRICS INGESTION

Prometheus Agent Mode

  • kube-prometheus-stack ทำหน้าที่เป็น In-memory Scraper สแครปข้อมูล Node, Pod, และ Container Metrics
  • ส่งข้อมูลตรงเข้า OpenObserve ผ่าน Prometheus Remote Write โดยไม่เปลืองพื้นที่ Local TSDB ของ Prometheus
  • สตรีมข้อมูลเข้า Stream ชนิด Prometheus พร้อมรองรับคิวรีผ่านภาษา PromQL ทันที
LOG PIPELINE

OpenTelemetry Collector

  • ติดตั้งแบบ DaemonSet ประจำทุก Worker Node เพื่อเก็บ Log ระดับ Container ทั้งหมด
  • ใช้ filelog receiver อ่านพาธล็อกตรงจาก /var/log/pods/*/*/*.log
  • สกัด Metadata สำคัญ (namespace, pod, container) ด้วย k8sattributes ก่อนยิง OTLP เข้า Stream k8s_logs
RETENTION & RESILIENCE

Storage & Auto-Compactor

  • MinIO S3 Backend (20Gi) จัดเก็บ Log และ Metric ในฟอร์แมต Parquet ถาวร ป้องกันข้อมูลหายเมื่อ Pod รีสตาร์ท
  • Data Retention 1 วัน (24 ชม.) ควบคุมด้วย ZO_DATA_RETENTION_DAYS: 1
  • Auto-Compactor (300s) เคลียร์บล็อกข้อมูลเก่าและรวมไฟล์ Parquet ขนาดเล็กทุก ๆ 5 นาที

COMMAND-LINE EXECUTION

ขั้นตอนการติดตั้งและเริ่มต้นใช้งาน

1. ติดตั้งระบบทั้งหมด (Deploy Stack) STEP 1

สั่งรันสคริปต์เพื่อสร้าง Namespace, ติดตั้ง OpenObserve Helm Release, kube-prometheus-stack, OpenTelemetry Collector DaemonSet และ Provision Dashboards:

./scripts/deploy.sh
2. ตรวจสอบสถานะความพร้อม (Health Check) STEP 2

ตรวจสอบสถานะ Pod ทุกตัว, Storage (PVC) ในสถานะ Bound, ค่าคอนฟิก Retention 1 วัน และการตอบกลับของ HTTP Web UI:

./scripts/verify-health.sh
AUTOMATED TEST SUITE & VERIFICATION

ชุดสคริปต์ทดสอบและตรวจสอบระบบ (E2E)

scripts/test-logs.sh Logs

Container Logs & Metadata Verification

ตรวจเช็กว่า OTel Collector ส่ง Container Logs เข้า Stream k8s_logs และสกัด Kubernetes Metadata (namespace, pod, container) ครบถ้วน

scripts/test-metrics.sh Metrics

Prometheus Metrics Stream Ingestion

ตรวจสอบการไหลเข้าของ Core Metrics (CPU, Memory, Container Usage, Pod Phases) ผ่าน Prometheus Remote Write

scripts/test-dashboards.sh PromQL

Declarative Dashboards Validation

ตรวจสอบว่าแดชบอร์ด Cluster Overview และ Workload Metrics ถูกสร้างและมีโครงสร้าง PromQL สมบูรณ์บน OpenObserve REST API

scripts/test-resilience.sh Resilience

Crash Simulation & Data Persistence

จำลองเหตุการณ์ Pod แครชโดยการสั่งลบ Pod แล้วตรวจสอบว่าหลัง Pod ใหม่เริ่มทำงาน ข้อมูล Logs และ Metrics บน MinIO ยังคงอยู่ครบถ้วน

scripts/run-all-tests.sh Master Suite

End-to-End Master Test Runner

รันการทดสอบทุกชุดแบบต่อเนื่อง พร้อมรายงานสรุปผล Pass/Fail ครบทุกมิติของระบบ

./scripts/run-all-tests.sh

การลบและคลีนอัปสภาพแวดล้อม (Cleanup)

เมื่อต้องการถอนการติดตั้ง สามารถเลือกลบเฉพาะ Helm Releases (คงข้อมูลใน PVC) หรือลบทั้งหมดแบบสมบูรณ์:

./scripts/cleanup.sh
./scripts/cleanup.sh --purge
